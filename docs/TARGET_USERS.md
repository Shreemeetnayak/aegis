# Target Users

## Primary Users

- Backend Developers
- Full Stack Developers
- DevOps Engineers
- AI Engineers
- Software Engineering Students

## Problems They Face

- Deployment failures with unclear error messages
- Large logs that are difficult to understand
- Configuration mistakes
- Missing environment variables
- Docker build failures
- Runtime crashes
- Difficulty understanding unfamiliar codebases

## What Aegis Does

Aegis understands repositories, analyzes deployments, retrieves relevant code, explains failures in plain language, and recommends actionable fixes backed by evidence.

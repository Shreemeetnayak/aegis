# AI Engineering Glossary

## Repository Ingestion
Downloading a GitHub repository so Aegis can work with it.

## Repository Analysis
Understanding what technologies, frameworks, and configurations the repository uses.

## Repository Indexing
Converting repository code into searchable knowledge.

## Embedding
A numerical representation of the meaning of text or code.

## Vector Database
A database that finds information by meaning instead of exact words.

## Retrieval (RAG)
Finding only the most relevant information before asking the AI to answer.

## Tool Calling
Allowing the AI to use external tools to fetch real information instead of guessing.

## Evidence
The files, logs, and configurations used to support an AI answer.

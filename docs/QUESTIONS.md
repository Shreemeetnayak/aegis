# Questions Aegis Should Answer

## Repository

- What framework does this project use?
- What database does it use?
- How do I run this project?
- What environment variables are required?

## Deployment

- Why did my deployment fail?
- Which build step failed?
- Is Docker configured correctly?

## Code

- Where is JWT authentication implemented?
- Which file connects to PostgreSQL?
- Where is this API endpoint defined?

## Security

- Are there exposed secrets?
- Are any dependencies vulnerable?
- Is this configuration safe?

## Performance

- Why is startup slow?
- Which queries are expensive?
- What can be optimized?

# AI Memory

## Short-Term Memory

Stores information only for the current conversation.

Examples:

- Current repository
- Current deployment
- Current logs
- Current user question

---

## Long-Term Memory

Stores information across deployments.

Examples:

- Previous deployment failures
- Successful fixes
- Repository history
- Deployment history

---

## Why Memory?

Memory allows Aegis to improve its recommendations by learning from previous deployments instead of treating every deployment as completely new.
